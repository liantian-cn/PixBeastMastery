# 核心 DPS 循环说明

本文只讨论猎群领袖兽王猎的核心 DPS，不把打断、减伤等非输出行为纳入优先级比较。

## 鞭笞与怒火

用户于 2026-10-02 提供并确认的高手总结：狂野鞭笞会增强狂野怒火，因此 AOE 时怒火要等鞭笞，且应是鞭笞后的第一个输出技能。这是本项目采用的经验，不是 Maxroll 原文；不能仅因其简化优先级把怒火列在前面，就将此顺序改回。

用户指定以玩家增益 **268877 / Beast Cleave / 野兽顺劈** 作为 AOE 怒火的判断条件。

## 当前实现

- AOE：顶部“狂野怒火增益期间优先鞭笞”的条件及动作已整段注释，保留代码、第 84 格及其 Context 属性和插件加载项。后面的常规狂野鞭笞分支仍要求集中值至少 35、鞭笞冷却为 0。
- AOE：狂野怒火冷却就绪、未处于收尾状态（`Isfinishing=False`）、玩家存在野兽顺劈，且野兽顺劈剩余时间严格大于 4 秒时，释放狂野怒火。该分支是当前核心 DPS 的最高优先级，高于倒刺射击和常规狂野鞭笞分支。不再检查鞭笞冷却；恰好 4 秒不满足条件。
- AOE 没有野兽顺劈时不释放狂野怒火，即使鞭笞正在冷却。
- 单体：保留原位置的狂野怒火分支，只要求冷却就绪、未处于收尾状态（`Isfinishing=False`），不要求野兽顺劈；符合提前条件的倒刺仍在它之前。
- 依据当前增益状态及剩余时间判断，不追踪上一技能，也不把“增益存在”解释为“刚刚释放了鞭笞”。满足条件的怒火先于常规鞭笞分支释放。
- 沿用现有战斗、目标和射程门控，其余输出技能顺序不变。

此前的实现仅要求 AOE 鞭笞进入冷却后才允许怒火，且高优先级倒刺可能插在两者之间。本次以顶部的野兽顺劈条件取代该 AOE 判断。

用户于 2026-10-02 曾确认追加狂野鞭笞剩余冷却小于 1.5 秒；后续确认以野兽顺劈 268877 剩余时间大于 4 秒替代该条件，并注释顶部怒火增益期间的鞭笞分支。

## 三态收尾与血量阈值

2026-10-03确认：第60格从布尔开关改为配置枚举，灰度0自动、10关闭、20开启。`Context.finishing` 返回整数模式，`rotation.py` 每轮计算局部变量 `Isfinishing`，单体与AOE的狂野怒火均要求该变量为False。

- 自动（默认）：首领战等同于第86格 `encounter_in_progress`，遭遇战中始终不收尾；否则，目标预测生命比例 `target_health_pct` 严格低于第87格 `finishing_health_threshold` 时收尾。异常模式值按自动处理。
- 关闭：始终不收尾。开启：始终收尾，包括遭遇战中；两者均不受血量阈值影响。
- 阈值默认20%，范围0–50%，滑块步进5；恰好等于阈值不收尾，0表示自动模式不收尾。每轮重新判断，切换目标、血量恢复不会保留此前状态。
- 收尾只禁止狂野怒火，不改变倒刺射击等其他技能的优先级，也不影响饰品和药水。
- 模式脱战、重载恢复自动，阈值与按钮位置持久化保存。按钮及 `/pix end toggle` 按自动→关闭→开启循环，`/pix end auto|off|on` 可直接指定。

第87格用灰度字节直接表示阈值，Python四舍五入读取，超出0–50回退20，合法的0保留。基板扩为356px，插件与Python必须配套更新。游戏内需验收三态按钮、命令、脱战与重载后的模式重置和阈值保存，以及遭遇战与血量阈值两侧的怒火行为。

## 状态读取与验收

第 76 格通过原生 AuraContainer 显示玩家野兽顺劈：存在为白色，不存在为黑色。Python 通过 `Context.player_has_buff_beast_cleave` 读取，插件与 Python 必须配套更新。

第 84 格以相同方式显示玩家狂野怒火增益 19574，通过 `Context.player_has_buff_bestial_wrath` 读取。更新插件后需在游戏内 `/reload`，并让 Python 重新定位扩展后的基板。

第 85 格通过 AuraContainer 的 DurationText 原生绑定和 `AuraRemaining` 曲线显示玩家野兽顺劈剩余时间，由 `Context.player_buff_beast_cleave_remaining` 解码为秒。0 表示不存在或到期，240 包含永久光环或上限饱和；4 秒附近理想精度为 0.1 秒，实际效果受渲染与采样影响。

游戏内需验证增益出现、倒计时、消失及重载后的色块状态，并检查 AOE 怒火在野兽顺劈剩余时间大于 4 秒时优先释放、顶部鞭笞分支停用、常规鞭笞分支保留，以及单体倒刺优先级和收尾开关。静态检查不能替代游戏内验收。
